# PlotLib 桌面程序：前端组件清单

> 2026-11-27。写给前端 Agent。根据 plotlib 库现有的公开接口整理，列出桌面程序需要的界面组件。
> 外观规范见 `GUI_WORK_PLAN.md` 3.5.1 和 `GUI_DESIGN_PROMPT.txt`；整体架构见 `GUI_WORK_PLAN.md` 第 3 节。
> 信号名、方法名都是**暂定**的，G4.5 接线时双方再定最终名字；组件放在哪一页、怎么排布由前端决定。

## 1. 所有组件都遵守的约定

**被动视图。** 组件只做两件事：

1. **发出操作**：用户的操作通过 Qt 信号发出去，参数只用普通 Python 数据（`str`、`int`、`float`、`bool`、`list`、`dict`、`None`）。
   组件自己不去执行操作，也不判断操作合不合法（合不合法由库在执行时报错，错误会显示在状态栏）。
2. **显示给它的数据**：提供 `set_xxx(普通数据)` 方法。数据由接线层从程序状态里读出来、转好以后交给组件。
   组件用这些方法刷新控件时，要用 `QSignalBlocker` 屏蔽自己的信号，否则「显示」会被当成「用户改了」再发出去。

**表单类组件**（一组设置项）统一提供：`values() -> dict`、`set_values(dict)`、信号 `changed(dict)`（任一项改动后发出完整的 `values()`）。

**不导入** `plotlib_gui.session`，不调用 plotlib 的方法；唯一例外是可以从 `plotlib.style` 读选项表的键当作下拉框选项（第 2 节），
这样选项只有一份来源。

**「不指定」是一个合法的值。** 库里大多数样式字段写 `None` 表示「不改，沿用默认」。所以：

- 下拉框第一项是「默认」，对应 `None`；
- 数字输入框可以留空，留空对应 `None`；
- 开关类用三态：默认（`None`）/ 是（`True`）/ 否（`False`）。

**`None` 的含义按字段来，不全是「默认」。** 表单发出的值和库的参数一一对应，翻译层（G4.2）按字段处理，不做统一转换。
下面这些字段的 `None` 有自己的意思，界面上的文字要按这个写：

| 字段 | 取值和含义 |
|---|---|
| 样式对象的字段（线宽、线型、边框、图例、刻度、柱样式等） | `None` = 默认（沿用下一层） |
| `legend_title` | `'auto'` = 自动；`None` = 不加标题；其他字符串 = 自定义 |
| 图层的 `x`、`y` | `None` = 用全局设置的 X、Y 通道 |
| 柱状图 `reduce` | `None` = 不汇总（每格至多一个值） |
| 柱状图 `errors` | `None` = 没有误差棒 |
| `figsize` | `None` = 按分图方式自动 |
| `plotrange` | `None` = 画全部数据点 |
| 颜色条 `limits` 的某一端 | `None` = 这一端自动 |
| 颜色条 `title` | `None` = 用颜色通道的列标题；`''` = 不显示标题 |

**数据集编号 `dataset_id`。** 由 Session 分配：从 1 开始的整数，只增不减，**删除后也不再使用**，所以一个旧编号永远不会指到另一个数据集上。
组件把它当作不透明的标识，只保存、回传，不做运算，也不拿它当列表下标。
**凡是作用于某个数据集的组件，在显示或打开时记住它的编号，发出的信号都带上这个编号**；不要在发信号时才去问「现在目录里选的是哪个」，
因为用户可能在窗口打开期间切换了目录里的选择。

**能单独运行。** 每个组件文件末尾带一个用假数据演示的 `if __name__ == "__main__":`，或者统一做一个组件画廊
（建议 `python -m plotlib_gui.panels.gallery`），不依赖数据文件和 Session 就能看到所有组件的各种状态（空、有数据、禁用、选中）。

**位置**：`src/plotlib_gui/panels/`（各组件）、`src/plotlib_gui/main_window.py`（主窗口），导入写完整路径。

## 3. 组件清单

按优先级分两批。第一批是「导入数据 → 分组 → 绘图 → 看图」跑通所需的，验收只看这条闭环；第二批可以晚一点。
工程文件的打开和保存、导出在 G4 之后才接通，组件可以先画，但不算第一批的验收项。

### 第一批

#### 3.1 主窗口 `MainWindow`

在现有骨架上改，菜单沿用骨架的「文件｜数据｜分组｜绘图｜视图」：

- **菜单**：
  - 文件：打开工程…（`*.plb`）、保存工程、工程另存为…、导出当前图…、退出（工程和导出在 G4 之后接通）；
  - 数据：导入数据…（打开 3.2 的导入对话框）、数据预览（第二批，3.16）；
  - 分组：新建分组…、保存分组方案…、载入分组方案…；
  - 绘图：折线图…、散点图…、柱状图…：各打开对应的绘图设置窗口（3.6、3.13），折线图和散点图打开的是同一个曲线图设置，只是新图层的默认画法不同；
    设置窗口里的「绘制」按钮才真正提交；
  - 视图：层叠窗口、平铺窗口、关闭全部窗口。
- **左栏**：「数据集 / 组 / 图形」三个页签都是目录：数据集页列出**所有数据集**并显示选中那个的内容（3.2、3.3），组页显示选中数据集上的分组（3.4），
  图形页显示绘图结果（3.9）。**支持多个数据集并存**（用户 11-27 定）：导入的数据和以后处理产生的子数据集都是独立的数据集，导入不会替换已有的。
- **中央**：`QMdiArea`，装图窗（3.8）。
- **状态栏**：见 3.10。
- **信号**：每个菜单项一个，如 `open_project_requested(path)`、`save_project_requested(path | None)`、`export_requested`。
  需要选文件的操作，由主窗口弹出文件对话框，选好后带上路径发出；取消就不发。
- **方法**：`set_title(str)`（如工程名）、`set_action_enabled(name, bool)`（比如没有数据时绘图菜单变灰；只是提示，不代替库的检查）。

#### 3.2 导入对话框 `ImportDialog` 和数据集列表 `DataSetList`（数据集页）

导入只有一个入口：菜单「数据 → 导入数据…」和数据集页的「导入…」按钮都打开同一个 `ImportDialog`。

- `ImportDialog`：选文件（路径）、**每个样品占几列**（整数，≥ 2，含样品名那一列；读数据必须要这个数）。点「导入」后发出
  `open_requested(path: str, columns_per_sample: int)`，两项一起发；取消什么都不发。导入的结果是**新增**一个数据集。
- `DataSetList`：列出所有数据集。数据集之间有来源关系（子数据集由某个数据集处理得到），用树形显示：导入的数据在顶层，处理得到的挂在来源下面。
  `set_datasets(datasets: list[dict])`，元素如 `{'id': 1, 'name': 'piezo.csv', 'parent': None, 'source': 'G:/data/piezo.csv', 'n_samples': 10, 'n_channels': 2, 'n_rows': 2000}`，
  子数据集的 `parent` 是来源的 `id`，`source` 是一句说明（如「归一化」）。`set_current(id)` 标出选中的那个。
- 交互：单击选中（组页、样品表都跟着显示这个数据集）；重命名、删除；「导入…」按钮。
- 信号：`current_changed(id)`、`rename_requested(id, name)`、`delete_requested(id)`。
  选中哪个数据集是界面状态，不进 Session；删除一个有子数据集或绘图结果引用的数据集会怎样，由 Session 决定（可能报错），界面不判断。

#### 3.3 样品表 `SampleTable`（数据集页，显示选中的数据集）

- 显示样品和通道的**元数据**，不显示数值（数值预览在第二批，3.16）：每行一个样品，列为样品号、样品名，后面每个通道一列显示该通道的列标题（含单位）。
  `set_samples(samples: list[dict])`，元素如 `{'id': 3, 'name': 'S3'}`；`set_channels(channels: list[dict])`，元素如 `{'id': 1, 'unit': "Zs'(ohm)"}`。
  样品号可能不连续（如 0、3、4），不要假设等于行号。
- 交互：多选样品。信号 `selection_changed(ids: list[int])`（用来「用选中的样品新建分组」）。

#### 3.4 分组列表 `GroupList`（组页，显示选中数据集上的分组）

每个数据集有自己的一套分组，互不通用（库里的 `Group` 必须建在同一个数据集上）。

- 显示：每行一个分组：组名、样品号列表、样式小样（颜色色块、线型、标记、纹理，没写的不显示）。
  `set_groups(dataset_id: int, groups: list[dict])`，组件记住这个编号；`groups` 的元素如 `{'name': 'A', 'num': [0, 3], 'color': '#1e40af', 'linestyle': 'dash', 'marker': None, 'hatch': None}`。
  刚由分组计算（`Group.apply`）等处理得到的子数据集没有分组，显示为空列表即可。
- 按钮：新建、编辑、删除。
- 信号都带上数据集编号：`add_requested(dataset_id)`（打开 3.5 的对话框）、`edit_requested(dataset_id, name: str)`、`delete_requested(dataset_id, name: str)`。

#### 3.5 分组编辑对话框 `GroupEditorDialog`

- 字段：组名；成员样品（**有顺序**：用可勾选、可上下移动的列表，顺序有意义，第一个样品决定合并图里的组首色）；
  可选样式：颜色、线型、标记、纹理（都可以「默认」）。
- 方法：`set_dataset(dataset_id: int)`（打开时绑定，之后不随目录里的选择变化）、`set_samples(samples)`（同 3.3，是这个数据集的样品）、
  `set_values(name: str, options: dict)`（编辑时填入现有分组的完整配置）。
- 下面两个信号的第一个参数都是绑定的 `dataset_id`。
- **新建**：组名可编辑。点「确定」后发出 `accepted_config(dataset_id, config: dict)`，形如 `{'A': {'num': [3, 0], 'color': '#1e40af', 'linestyle': 'dash'}}`，只放写了的样式字段。
- **编辑**：组名锁定，不可改（库的 `Group.set` 按组名找到分组、替换整份配置；改名以后另作一个动作）。
  点「确定」后发出 `accepted_edit(dataset_id, name: str, changes: dict)`，`changes` **只放用户动过的字段**：改成新值的给新值，用户明确选了「默认」（重置）的给 `None`，
  没动过的字段不出现。接线层在原配置的**副本**上应用：非空值覆盖，`None` **删除这个键**（库的 `Group.set` 收到 `color=None` 会报错，省略这个键才是恢复默认），
  再把完整配置交给 `Group.set`，这样编辑器不认识的字段和写法都原样保留。
- 原配置里可能有编辑器表示不了的写法：库还接受 CSS 颜色名（如 `'red'`）、RGB 三元组、自定义虚线（如 `(6, 2)`）。
  遇到这种值，对应控件显示为「自定义（保持原样）」，用户不动它就不出现在 `changes` 里。
- 点「取消」什么都不发。对话框里没点确定的修改只留在对话框里。

#### 3.6 曲线图设置 `CurvePlotForm`（从「绘图」菜单打开的设置窗口，表单类）

对应库的 `DataPlotter.plot(...)`。打开时由接线层用上一次提交的设置填入（`set_values`）。窗口里的编辑何时进入程序状态，见第 4 节后端答复第二轮第 3 条：

| 字段 | 控件 | 说明 |
|---|---|---|
| `dataset` | 下拉 | 画哪个数据集，值是 `dataset_id`（选项由 `set_datasets` 给出，同 3.2；第一次打开时默认是数据集页选中的那个，之后以下拉里的为准，不随目录选择变化）。一次绘图只用一个数据集。切换后由接线层用 `set_channels`、`set_groups` 换成新数据集的通道和分组选项；已选的通道在新数据集里没有时，保留原值并标成「此数据集没有」，让用户重选，不自动改成别的通道（提交了库会报错） |
| `by` | 三选一 | 分图方式 |
| `merge_groups` | 勾选 | 只在 `by='group'` 时可用：所有分组画在一张图上 |
| `legend_title` | 下拉 + 文本 | 「自动」= `'auto'`，「不加」= `None`，或自定义文字（可含 `{name}`，会换成每张图的名字） |
| `layers` | 图层列表（3.7） | |
| `colorbar` | 颜色条设置 | 只在有图层用了颜色映射时可用：色带、范围（下限、上限，各自可空 = 自动）、刻度类型、标题。标题是三选一：「自动」= `None`（用颜色通道的列标题）、「无标题」= `''`、「自定义」+ 文本。关掉最后一个颜色映射时不要清空这些设置，下次再开映射还在；要不要传给库由翻译层判断 |
| `backend` | 二选一 | matplotlib / plotly |

另有一个醒目的「绘制」主按钮，信号 `plot_requested(values: dict)`，带上当前完整的设置。

#### 3.7 图层列表 `LayerList`（曲线图设置窗口里）

一张图可以有多个图层，每行一个，可增删、上下移动：

| 字段 | 控件 |
|---|---|
| `x`、`y` | 通道下拉（选项由 `set_channels(channels)` 给出，同 3.3；「默认」= `None`） |
| `kind` | 折线 / 散点 |
| `side` | 左轴 / 右轴 |
| `neglog_x`、`neglog_y` | 勾选（负值取绝对值画在对数轴上） |
| `mapping` | 只在散点时可用：颜色通道（可空）、大小通道（可空）、大小范围（最小、最大直径，默认 4、16） |

`values()` 返回 `list[dict]`，元素如 `{'x': 0, 'y': 1, 'kind': 'scatter', 'side': 'left', 'neglog_x': False, 'neglog_y': False, 'mapping': {'color': 2, 'size': None, 'size_range': [4, 16]}}`，没有映射时 `'mapping': None`。

#### 3.8 图窗 `FigureWindow`（`QMdiArea` 的子窗口）

- 外框和标题栏由前端画（规范见 3.5.1）。标题：图名，必要时带批次号。
- 窗口内容不由前端画：提供 `set_content(widget: QWidget)`，接线层会放进 matplotlib 画布或网页视图；
  再提供 `set_toolbar(widget: QWidget | None)`，用来放 matplotlib 的缩放、平移工具条。
- 信号：`closed(window_id)`、`activated(window_id)`。`window_id` 由接线层在创建时给出（`set_window_id`）。
- 目录条目和窗口不是一一对应的，对应关系由接线层管（界面状态，不进 Session）：matplotlib 结果一张图一个窗口；
  Plotly 一批结果是一个多页的图，整批共用一个窗口。

#### 3.9 绘图结果目录 `ResultTree`（图形页）

- 显示两层：批次 → 图。`set_results(batches: list[dict])`，元素如
  `{'id': 2, 'title': '#2 piezo.csv · 按分组 · 9 张', 'dataset': 1, 'figures': [{'key': 'A', 'title': 'A', 'open': True}, ...]}`（标题里带上画的是哪个数据集）。
  `key` 可能是字符串（分组名、`'main'`）也可能是整数（样品号）。Plotly 批次只有一条 `{'key': None, 'title': '全部页', ...}`。
  已打开的图要能看出来（`open` 由接线层按实际窗口回填）。
- 交互：**单击只选中**，双击或回车才打开（已打开的就激活那个窗口），避免浏览目录时连续开窗。
- 信号：`open_requested(batch_id, key)`、`delete_batch_requested(batch_id)`、`export_requested(batch_id, key | None)`。
  删除批次时，接线层先关掉这批的窗口，再释放图。

#### 3.10 状态栏 `StatusStrip`

- `show_message(text: str, level: str)`，`level` 为 `'info'`、`'success'`、`'error'`；错误信息可能较长（库的报错是一整句话），要能完整看到（如悬停提示或点开详情）。
- `set_busy(bool)`：正在绘图时显示忙碌状态。
- 右侧常驻：数据集概况，`set_summary(text)`。

### 第二批

#### 3.11 外观设置 `AppearanceForm`（表单类，放哪里由前端定，可以是对话框）

对应 `DataPlotter(...)` 的构造参数，作用于之后的所有绘图：

| 分组 | 字段 |
|---|---|
| 整体 | 字体 `font_family`、字号 `font_size`（磅）、字重 `font_weight`、样品配色色带 `cmap`、图尺寸 `figsize`（宽、高，英寸，可空 = 按分图方式自动）、`dpi`、只画前 N 个点 `plotrange`（可空） |
| 线条 `lines` | 线宽、线型、标记、标记大小（**没有颜色**：颜色按样品自动配，或在分组里指定） |
| 边框 `frame` | 线宽、上边框（三态）、右边框（三态） |
| 图例 `legend` | 位置、字号、边框（三态）、可拖动（三态） |
| 刻度 `ticks` | 方向、主刻度长 / 宽、显示次刻度（三态）、次刻度长 / 宽、刻度文字字体 / 字号 / 间距、次刻度文字（`none` / `short` / `full`）及其字体 / 字号 / 间距 |

`values()` 形如 `{'font_size': 22, 'lines': {'width': 2, 'linestyle': None, ...}, 'frame': {...}, ...}`，没写的为 `None`。

#### 3.12 坐标轴设置 `AxisForm`（表单类）

X 轴、左 Y 轴、右 Y 轴各一份，字段相同：刻度类型、范围（下限、上限，各自可空）、刻度文字格式（文本，如 `{x:.2f}`、`{y:.1e}`）、
显示倍率 `scaler`（只改刻度文字，不改数据；只有 matplotlib）、轴着色（颜色）。

#### 3.13 柱状图设置 `BarPlotForm`（从「绘图 → 柱状图…」打开的设置窗口，表单类）

对应 `DataPlotter.plot_bars(...)`，同样有「绘制」按钮和 `plot_requested(values: dict)`：

| 字段 | 控件 |
|---|---|
| `dataset` | 同 3.6 |
| `channels` | 通道多选，有顺序 |
