请为 PlotLib 设计一个 PySide6 / Qt Widgets 科学绘图工作台。按窗口实际支持的功能安排数据、分组、通道、预览和导出。图表占主列，设置占辅列。

设计来源

- 以 Minimalist Flat 为主体。先读 StyleKit MCP 的 brief、tokens 和 button / card / input 组件配方，再核对展示页。沿用这套风格的布局、几何、字号、留白、交互和信息层级。
- 用两档浅蓝灰作为界面底色。#F1F5F9 用于窗体底色，#F8FAFC 用于菜单栏、卡片、预览画布和状态栏，#0F172A 用于主文字、区域轮廓和主分隔线。细分隔线和图表网格用 #E5E7EB。#1E40AF 用于主要操作、菜单选中态和当前曲线，#3B82F6 用于按下和焦点，#64748B 用于辅助文字、控件底线、线条图标和比较曲线。#10B981 与 #C559F0 分别留给明确的成功状态和实验性标记。
- 中文用思源黑体简体。英文和全部数字用 San Francisco（SF Pro），包括中英文混排里的数字、样品序号、坐标刻度和图例。系统缺少 SF Pro 时，Qt 和 Matplotlib 优先回退 Inter。本机可用的 Adobe 思源黑体文件可放在 gui/fonts/SourceHanSansCN-VF.otf，由主窗口和预览脚本直接加载。也支持系统安装的思源黑体。

布局与几何

- 用左对齐的瑞士栅格，最大内容宽度 1280 px。以 8 px 为间距单位，外侧留白 24 px，绘图区和设置区之间留 24 px，面板内留 32 px。可滚动的多节页面按参考的 128 px 节间距排版。单屏绘图工作台用 32 px 分隔标题和工作区，为数据画布留空间。
- 采用 64 px / 900 主标题、24 px / 700 面板标题、16 px / 400 正文、12 px / 700 标签。大标题紧排，短数字标签略疏，图例和单位用常规字重。
- 使用直角、2 px 深色实线、纯色块和负空间。菜单及弹出面板、设置区、绘图区和状态区用深线界定边缘。菜单选中项在局部用企业蓝填充。形状由矩形、直线和简洁线条图标组成。以颜色切换表达层级，避免阴影、渐变、纹理和位移动画。
- 实心与描边按钮采用 2 px 边框和 16 × 32 px 内边距。悬停时前景与背景互换，按下用亮蓝实色和深色字，聚焦改变边框。Qt 对齐 Showcase 的即时反色。输入框和下拉框保留 2 px 底线，聚焦改变底线色。滑块采用细水平轨道和方形手柄。禁用态降低对比度，Tab 和方向键保持可用。

绘图与复用

- 图表预览用浅蓝灰底、石板灰轴线、深色刻度文字和淡色主网格。用颜色与线型共同区分曲线，当前曲线以主蓝突出。示例导出的 PNG 用白底。已有样品配色与科学语义优先。
- Qt 样式表负责控件外观，Qt 布局管理器负责尺寸和间距，FigureCanvasQTAgg 承载 Matplotlib。用 Figure、Axes 和字体属性设置预览，不在全局改 rcParams。接入已有窗口时复用 PlotLib 的数据流和绘图接口。
